## What the HMOS layer adds

The Balanced Scorecard remains the strategic measurement layer. HMOS embeds it in a chain of **position, evidence, control, review, corrective action, and institutional memory**.

> Expected condition → Actual evidence → Managerial control → Result → Evaluation → Action → Institutionalization

A KPI is incomplete without identifiable evidence. Accountability sits in the **office**, not the personality.
